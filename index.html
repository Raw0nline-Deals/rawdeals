How to use a coupon code

  1. Copy the code: tap the code on a deal card to copy it.
  2. At Amazon checkout, find the option to add a gift card or promotion code. On Amazon it sits in the payment section and reads something like “Enter a gift card, voucher or promotional code.”
  3. Paste the code there, tap Apply, and check that the discount shows in your order total before you place the order.

Some deals apply the discount automatically or use an on-page coupon checkbox, so no code is needed.

When a card says “discount applied at checkout,” open that link. Amazon applies the discount, and there is no code to copy. The date on the card is the last day that offer is listed.
